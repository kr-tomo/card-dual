# 카드 테마(스프라이트) 폴더

이 폴더의 PNG 파일 하나가 카드 테마 하나입니다. **테마 이름 = 파일 이름**(확장자 제외)이고, 게임 아래쪽의 🎨 버튼을 누르면 이름 목록이 나옵니다. 첫 카드를 고르기 전에만 바꿀 수 있고, 선택한 테마는 기기에 기억됩니다.

## 테마 추가하기
1. 아래 시트 규칙대로 PNG를 그려서 이 폴더에 넣습니다. (예: `themes/ocean.png` → 테마 이름 `ocean`)
2. 목록을 갱신합니다: `node tools/update-themes.js` (이 스크립트가 `themes/themes.js`를 다시 씁니다). 스크립트를 못 돌리면 `themes/themes.js`의 목록에 이름을 직접 추가해도 됩니다.
3. 이미 설치한 PWA에서 안 보이면 `sw.js` 맨 위의 `CACHE` 이름(`memory-duel-v3`)을 올려 주세요 (예: v4).

## 시트 규칙 (모든 테마 공통, `themes/config.js`)
- 가로 8칸 × 세로 7칸, 한 칸 192×192px (전체 1536×1344), 배경 투명 PNG
- 칸 번호는 왼쪽 위부터 가로 방향: 0, 1, 2 … (한 줄 8칸)
- 0~47: 카드 앞면 48종 / 48: 카드 뒷면 문양 / 49: 누름돌
- 앞면은 한 칸 가운데에 그리면 됩니다 (카드 크기의 약 78%로 표시됨)
- 칸 크기나 줄 수를 바꾸려면 `config.js`의 `cell`, `cols`, `rows`를 수정 (모든 테마가 같은 규칙을 씁니다)
- 8×12 배치에는 앞면이 최소 48종 필요합니다. 종류가 모자라면 큰 배치 버튼은 막힙니다.

## 기타
- `default`(config.js): 처음 쓸 테마 이름. 저장된 테마가 목록에 없으면 이 값으로 돌아갑니다.
- 시트를 못 불러오면 `config.js`의 `emoji` 글자로 자동 대체됩니다.
- `node tools/make-sprite.js`로 기본 테마(emoji, letters)를 다시 만들 수 있습니다 (playwright 필요).
